# docs/media — the pictures, and what each set is for

This directory is not a screenshot dump. It is **the working record of every
change to this game that had to be judged by eye**, and it is committed
deliberately: the repository is MIT and meant to be learned from, and the
before/after pairs are often the most instructive thing in it. A commit message
can tell you a wall got taller. Only the pictures tell you whether that helped.

**None of it is loaded by the game.** Nothing here is an asset. Every image was
produced by a probe under `tests/qa/`, and every one can be regenerated by
re-running that probe — the command is listed with each set below.

---

## Why there are eleven versions of a spider

Because the first six were wrong, and the only way anyone found that out was by
looking. `docs/media/bosses/` holds 91 folders across 14 bosses, and the naming
is the history: `arachnid-v1` through `arachnid-v6`, then `arachnid-thin`,
`arachnid-anatomy`, `arachnid-NEW-truepitch`, `arachnid-final`. Reading them in
order is a record of a redesign actually happening, including the parts that did
not work.

Two of those names carry a lesson worth spelling out:

- **`-BEFORE` / `-AFTER`** pairs exist because "it looks better now" is not a
  measurement. Several changes in this project raised every number they were
  judged by and made the game look *worse*; the pair is what caught it.
- **`-truepitch`** exists because the boss portraits were being shot at a
  camera angle **the game does not use**. A comment in `camera-rig.js` had
  described the rig's unused default as if it were the real camera, that error
  propagated into a document, and out of the document into the probe. Fourteen
  bosses were photographed at the wrong angle before anyone checked. The folders
  from before and after that discovery are both here.

## The sets

| folder | what it shows | regenerate with |
|---|---|---|
| `certification/` | The 44 certification captures — 14 dungeons × (entry room + boss room), plus 8 overworld regions × 2 moods. `CERTIFICATION.md` links these, and columns C, D and H are certified by eye from them. **The nearest thing here to a formal record.** | `node tests/qa/certification-captures.mjs` |
| `bosses/` | The boss redesign, 91 folders deep. Silhouette, shadow, and in-game shots per attempt. | `node tests/qa/boss-portraits.mjs` |
| `player/` | The hero's own passes: `before/`, `after/`, `review/`, `warden-after/`. | `node tests/qa/player-captures.mjs --set=…` |
| `menus/` | Every menu screen — title, pause, settings, controls, beat select, scores, altar, run mode — plus `menu-captures.json`. Shot when the menus stopped being a debug surface. | `node tests/qa/menu-captures.mjs` |
| `telegraphs/` | Boss attack telegraphs, drawn against where the attack actually lands. Five shipped drawn one size and resolving at another; these are how that was found. | `node tests/qa/telegraph-shots.mjs` |
| `light-line/` | The Light Caster's standing line. | `node tests/qa/light-line-look.mjs` |
| `wall-height/` | The wall rake: each room shot from five player positions, and every dungeon shot with the hanging dressing hidden and shown. The `-dressed` / `-bare` pairs are the only way to tell a new banner from a wall that was always there. | `node tests/qa/wall-height-probe.mjs <beat>`<br>`node tests/qa/dressing-shots.mjs <beat>` |
| `title/` | The title screen, before and after it stopped being text on a rendered scene. | `node tests/qa/title-shot.mjs [level]` |
| `quality/` | The hero at each graphics tier, and with each ultra-only effect switched off one at a time. `-aberration-*` is a sweep of chromatic aberration strength. **This set is the whole diagnosis of why ULTRA looked worse than LOW** — the numbers said the tiers were identical and the pictures did not. | `node tests/qa/quality-hero.mjs`<br>`node tests/qa/aberration-cost.mjs` |

## Everything is here

There is no `.gitignore` rule under this directory. There was one — it excluded
the 44 HUD-hidden `-clean` twins of the player captures, on the reasoning that
`certification/` already covers HUD-free frames — and it was removed, because a
comparison set with a third of its frames missing is not a comparison set. The
HUD frame, the greyscale twin and the clean twin are three views of one decision
and they are worth more together than apart.

Cloning the whole history is a few hundred megabytes. If you only want to play
or build the game, `git clone --depth 1` skips it.

## If you are reading this to learn something

The single most useful habit in this directory is **shoot it twice**. Every
probe that produces a pair — before/after, dressed/bare, tier-on/tier-off — does
so because a single image cannot tell you what changed, and because this project
repeatedly found that its *instruments* were broken rather than its game. A
metric that says "no difference" and a pair of pictures that plainly differ is
not a tie; it means the metric is measuring the wrong thing, and the pictures
are the ones that get to be right.
